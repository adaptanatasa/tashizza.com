Prvi deo: Bash kao jezik Linux svakodnevice

Bash je prvi pravi razgovor sa Linux sistemom. Kroz komandnu liniju učimo kako sistem vidi fajlove, direktorijume, procese, korisnike, dozvole, tekst, izlaz komandi i tok podataka. Ovaj deo praktikuma gradi sigurnost u terminalu i uvodi skriptovanje kao prirodan nastavak svakodnevnog rada.

I. Terminal, komande i način razmišljanja

1. Terminal – radni sto Linux korisnika 2. Komande – kako razgovaramo sa sistemom 3. Putanje – gde se nalazimo i gde želimo da idemo 4. Fajlovi i direktorijumi – osnovni objekti sistema 5. Pomoć i dokumentacija – kako samostalno tražimo odgovore

II. Tekst, izlazi i tokovi podataka

6. Tekstualni fajlovi – čitanje, pregled i osnovna obrada 7. Redirekcije – ulaz, izlaz i greške 8. Pipeline – povezivanje komandi u tok rada 9. grep, sort, uniq i wc – prve alatke za analizu teksta 10. sed i awk – kada tekst postane podatak

III. Bash skripte

11. Prva Bash skripta – od komande do programa 12. Promenljive – pamćenje vrednosti u skripti 13. Uslovi – ako je ovo, uradi ono 14. Petlje – ponavljanje bez zamora 15. Funkcije – uredno slaganje logike

IV. Automatizacija Linux zadataka

16. Dozvole i korisnici – sigurnost u skriptama 17. Procesi – pokretanje, praćenje i zaustavljanje 18. Logovi – čitanje tragova sistema 19. cron – zadaci koji se sami pokreću 20. Bash praktikum – male skripte za velike uštede vremena

Drugi deo: Python kao jezik jasne automatizacije

Python nastavlja tamo gde Bash postaje tesan. Kada zadatak traži jasniju strukturu, rad sa složenijim podacima, čitljiviji kod i lakše održavanje, Python postaje prirodan saveznik Linux korisnika. Ovaj deo uvodi osnove programiranja kroz praktične primere koji se oslanjaju na stvarne potrebe iz rada sa sistemom.

V. Python osnove

21. Python okruženje – pokretanje programa na Linuxu 22. Prvi Python program – čitljiv kod od prvog koraka 23. Tipovi podataka – brojevi, tekst i logičke vrednosti 24. Liste i rečnici – podaci koje možemo da uredimo 25. Uslovi i petlje u Pythonu – logika koja se lako čita

VI. Funkcije, fajlovi i moduli

VII. Python za Linux automatizaciju

VIII. Bash i Python zajedno
